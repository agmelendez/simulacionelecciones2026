Acerca del Proyecto

Este proyecto utiliza modelos estadísticos y machine learning en Python para simular y predecir resultados de las elecciones presidenciales 2026. El análisis se basa en datos históricos, encuestas y variables socioeconómicas.

Metodología

Proceso de Simulación

  1. Recopilación de Datos: Datos históricos electorales, encuestas y variables socioeconómicas
  2. Preprocesamiento: Limpieza, normalización y validación de datos
  3. Modelado: Aplicación de algoritmos de machine learning (regresión, clasificación, ensambles)
  4. Validación: Cross-validation y testing con datos históricos
  5. Simulación: Ejecución de múltiples escenarios con Monte Carlo

Tecnologías Utilizadas

Python Pandas NumPy Scikit-learn Matplotlib Seaborn
