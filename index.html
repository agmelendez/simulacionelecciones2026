Acerca del Estudio

¿Qué se hizo y por qué?

Se creó un modelo matemático que simula la elección 100,000 veces para entender qué tan probable es que se defina la presidencia en primera ronda. Esto se hace porque las encuestas son solo una "foto" del momento, mientras que este modelo mide la incertidumbre y el riesgo de cambios futuros.

¿De dónde vienen los datos?

Se utilizaron encuestas de alta calidad (tipo papeleta) con mayor peso a las mediciones recientes de enero de 2026, especialmente la del CIEP-UCR. Las encuestas de octubre y noviembre de 2025 tienen peso significativamente menor debido al decaimiento temporal.

Los supuestos del modelo (v2.1)

  • Corrige los sesgos específicos de cada encuestadora ("efecto de casa").
  • Trata a los indecisos (32%) como el factor clave que definirá el resultado.
  • Ajuste de Logit-Normal mejorado con correlación entre candidatos del mismo bloque ideológico.
  • Nuevo escenario de "Dispersión" donde indecisos migran a candidaturas minoritarias.

Cómo Funciona Este Repositorio

Estructura del Proyecto

Este repositorio contiene todos los componentes del análisis electoral:

  • Modelo_de_Simulación_Elecciones.ipynb - Notebook de Python con el código completo
  • Articulo Modelo de Simulación Elecciones CR 2026.pdf - Documento académico completo
  • DOCUMENTO_TECNICO_METODOLOGIA.txt (1).pdf - Metodología técnica detallada
  • resumen_candidatos_final.csv - Datos de resultados por candidato
  • top2_pairs_final.csv - Análisis de combinaciones
  • Resultados del modelo.jpeg - Visualización principal
  • simulacion_final_integrada (1).png - Gráfico de simulación

Clonar el Repositorio

Para obtener una copia local del proyecto:

git clone https://github.com/agmelendez/simulacionelecciones2026.git
cd simulacionelecciones2026

Ejecutar el Análisis

Requisitos: Python 3.8+, Jupyter Notebook

# Instalar dependencias
pip install pandas numpy matplotlib seaborn scipy jupyter

# Abrir el notebook
jupyter notebook "Modelo_de_Simulación_Elecciones.ipynb"
